You can get FleetForge running locally in about a minute. The project is a single-page React application with no backend, no database, and no configuration files to edit.

## Prerequisites

- Node.js 18 or later
- npm 9 or later
- A modern browser with WebGL support (Chrome, Firefox, Edge, or Safari)

## Install and run

<Steps>
  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/anmay001/fleetforge.git
    cd fleetforge
    ```
  </Step>
  <Step title="Install dependencies">
    <CodeGroup>

    ```bash npm
    npm install
    ```

    ```bash pnpm
    pnpm install
    ```

    ```bash yarn
    yarn install
    ```

    </CodeGroup>
  </Step>
  <Step title="Start the dev server">
    ```bash
    npm run dev
    ```

    Vite serves the app at `http://localhost:5173`.
  </Step>
  <Step title="Open the app">
    Navigate to `http://localhost:5173` in your browser. The dashboard loads immediately and the simulation starts with 5 AMRs and a pre-seeded task queue.
  </Step>
</Steps>

## Verify it works

When the app loads, confirm the following:

- The 3D warehouse floor is visible with 5 robot models moving along lanes.
- The KPI strip shows active robots, tasks, completed deliveries, and average battery.
- The event feed streams timestamped state changes and task events.
- The task queue grows as the generator adds new pickup-and-drop tasks.

## Other commands

| Script | Command | Purpose |
| --- | --- | --- |
| `dev` | `vite` | Start the development server with HMR |
| `build` | `tsc && vite build` | Type-check and emit the production bundle to `dist/` |
| `preview` | `vite preview` | Serve the production build locally |
| Type-check | `npx tsc --noEmit` | Run a strict type-check without emitting files |

<Note>
  FleetForge requires no environment variables, no `.env` file, and no external API keys. All state is stored in memory and resets when the page reloads.
</Note>
